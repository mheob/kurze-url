# lines starting with "#" are ignored by the loader.

# ValidatePassword (policy.go) compares this list against the normalized
# password for exact equality, never as a substring — so every entry here
# must already be normalized: lower-case, [a-z0-9] only, umlauts already
# transliterated the way normalizeForPolicy does it ("gruenwald", never
# "grünwald"). Anything else can never match and is dead weight.
#
# List a password here if it is one a link-sharer plausibly picks, in German
# or English: a real word, name, keyboard pattern, or date — not a
# random string, and not every "word plus a trailing digit" combination this
# list happens not to cover. This is a curated shortlist, not a corpus.
#
# The one deliberate exclusion: "passwort1" is not listed, even though
# "password1" is. policy_test.go pins ValidatePassword("passwort1", ...) as
# accepted — the documented floor the length/repetition/context rules set —
# and listing it here would reject it as "too_common" instead.
