#
# "passwort1" / "password1" — policy_test.go pins "passwort1" as an accepted,
# policy-compliant weak password: the documented floor the length/repetition/
# context rules set, not a guarantee this list catches every "common word
# plus a trailing digit" combination (it plainly does not — see "kennwort1",
# "welcome1", "qwerty1" below — those just happen not to collide with a test).
#
# "sommerfest" (bare or year-suffixed) — it doubles as this project's own
# worked example of a context-derived password (see gruenwald in
# policy_test.go), and a common-list hit here would report "too_common"
# instead of the more informative "derived_from_context".
